# Avar Dub — русско-аварский дубляж видео

**Avar Dub** — экспериментальный некоммерческий проект для помощи в озвучке фильмов, мультфильмов и других видео **с русского на аварский язык**. Цель — сделать доступным удобный инструмент для сохранения и использования аварского языка в аудиовизуальном контенте, а не создавать SaaS или коммерческий сервис.

> **Статус:** работающий локальный прототип. Проверен тестовый дубляж четырёх реплик мультфильма. Качество произношения, синхронизация и разделение исходного звука пока требуют улучшения.

## Что умеет сейчас

1. Извлекает аудио из видео с помощью FFmpeg.
2. Распознаёт русскую речь и получает таймкоды с помощью Faster-Whisper.
3. Хранит реплики в `segments.json`; перевод на аварский сейчас вводится **вручную**.
4. Генерирует аварскую речь через локальную модель **Silero TTS**, голос `b_ava`.
5. Уменьшает шипение и шумы с помощью `noisereduce`.
6. Размещает реплики на временной шкале и собирает MP4 через FFmpeg.
7. Сохраняет отчёт `output/segments_timing.json` с длительностями, превышениями и пересечениями реплик.

**Ограничения:** исходная звуковая дорожка в результирующем видео пока полностью заменяется — музыка и эффекты не сохраняются. Реплики, выходящие за исходные таймкоды, не ускоряются и могут накладываться друг на друга. Тестовая сборка ограничена 45 секундами. Автоматический перевод пока не интегрирован.

## Используемые технологии

| Компонент | Назначение |
| --- | --- |
| Python 3.12 | Основной язык проекта |
| [uv](https://docs.astral.sh/uv/) | Управление окружением и зависимостями |
| [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper) | Распознавание русской речи и таймкоды |
| [Silero Models](https://github.com/snakers4/silero-models) / `v4_cyrillic.pt` | Синтез аварской речи, `b_ava` |
| PyTorch | Загрузка и выполнение Silero |
| [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) | Встроенный исполняемый FFmpeg, без отдельной установки в PATH |
| NumPy / SoundFile | Обработка и сохранение аудио |
| noisereduce | Снижение шипения и шумов |
| JSON | Реплики, переводы и отчёты о таймингах |

## Структура проекта

```text
avar-dub/
├── pyproject.toml           # Зависимости uv
├── uv.lock                  # Создаётся командой uv lock (желательно коммитить)
├── README.md
├── .gitignore
├── transcribe.py            # Распознавание русской речи
├── dub.py                   # Генерация и сборка дубляжа
├── input.mp4                # Исходное видео (не коммитить)
├── segments.json            # Таймкоды и ручной перевод (не коммитить)
├── v4_cyrillic.pt           # Локальная модель Silero (не коммитить)
├── audio/                   # Промежуточные WAV
└── output/
    ├── avar_dub.wav
    ├── dubbed.mp4
    └── segments_timing.json
```

> Файлы `transcribe.py`, `dub.py`, `v4_cyrillic.pt` и `input.mp4` **не входят** в этот комплект конфигурации: используются уже созданные файлы твоего локального проекта. Сохрани их в корне проекта. `pyproject.toml` фиксирует основные зависимости, но конкретные версии существующего окружения не были предоставлены — перед стабильным развёртыванием проверь совместимость и зафиксируй `uv.lock`.

## Установка на Windows (PowerShell)

### 1. Установить uv

```powershell
winget install --id=astral-sh.uv -e
```

Перезапусти терминал и проверь:

```powershell
uv --version
```

### 2. Создать окружение и установить зависимости

Открой папку проекта, содержащую `pyproject.toml`:

```powershell
cd D:\Project\avar-silero-test
uv python install 3.12
uv sync
```

`uv sync` создаёт `.venv` и устанавливает зависимости из `pyproject.toml`. Активировать окружение необязательно: команды можно запускать через `uv run`.

Если у тебя уже есть работающее `.venv`, **не удаляй его до проверки**: сначала сравни установленные версии с новым окружением. При первой синхронизации uv может изменить существующие пакеты.

### 3. Подготовить модель и видео

Помести в корень проекта:

- `input.mp4` — видео с русской речью;
- `v4_cyrillic.pt` — используемую модель Silero;
- `transcribe.py` и `dub.py` — рабочие скрипты проекта.

### 4. Распознать русскую речь

```powershell
uv run python transcribe.py
```

Результат: `segments.json` с таймкодами и русскими репликами. Распознавание может ошибаться, особенно на музыке и песнях: **проверь текст и таймкоды вручную**.

В рабочем `transcribe.py` аудио предварительно извлекается через `imageio_ffmpeg` в NumPy float32, mono 16 kHz. Это обходит встречавшуюся ошибку несовместимости PyAV (`metadata_errors`).

### 5. Заполнить аварский перевод

В `segments.json` у нужных реплик заполни поле `ava`:

```json
[
  {
    "id": 1,
    "start": 18.72,
    "end": 23.58,
    "ru": "В одном селе жил когда-то пёс.",
    "ava": "Цебе заманалда цо росулъ гӀумру гьабун букӀун буго гьой."
  }
]
```

Это пример одной реплики. Поле `ava` у остальных реплик можно оставить пустым: они будут пропущены при озвучке. Важна корректная аварская орфография, в том числе символ **Ӏ** (палочка), который не следует автоматически заменять цифрой `1`.

### 6. Сгенерировать дубляж

```powershell
uv run python dub.py
```

Ожидаемые файлы:

- `output/dubbed.mp4` — тестовое видео с аварской речью;
- `output/avar_dub.wav` — отдельная дорожка дубляжа;
- `output/segments_timing.json` — отчёт о длительностях и пересечениях;
- `audio/` — промежуточные WAV-файлы.

В текущем `dub.py` параметр `MAX_VIDEO_DURATION = 45` ограничивает тестовую сборку первыми 45 секундами. Чтобы обработать всё видео, поставь `MAX_VIDEO_DURATION = None`.

## Предупреждения о длительности

Длительность русской и аварской реплик может различаться. Поэтому скрипт сохраняет технические поля для будущего редактора:

- `tts_duration` — фактическая длительность синтезированной реплики;
- `available_duration` — длительность исходного интервала;
- `overflow_seconds` и `overflow_percent` — насколько реплика длиннее интервала;
- `actual_end` — расчётное время окончания;
- `overlap_next_seconds` / `overlap_next_id` — пересечение со следующей озвученной репликой;
- `truncated_by_video` — обрезка концом выходного видео;
- `status` — результат обработки (`generated`, `untranslated`, `outside_output` и т. п.).

**Важно:** предупреждение не означает пропуск реплики. На текущем этапе сохраняется естественная скорость речи, а пересечения только обнаруживаются. В дальнейшем UI будет показывать предупреждения и давать возможность исправить перевод и пересоздать отдельную реплику.

## Что дальше

1. **Отделение исходных голосов от музыки и эффектов.** Проверить Demucs и/или другие модели разделения аудио на коротком фрагменте. Качество отделения диалогов не гарантируется.
2. **Синхронизация реплик.** Учитывать паузы, длину соседних реплик, допустимое ускорение и пересечения; не обрезать речь без предупреждения.
3. **Качество TTS.** Уменьшить роботизированный акцент и шипение, проверить произношение аварских звуков (в том числе `чӀ` и `й`), исследовать доступные голоса и альтернативные модели.
4. **Разные персонажи.** Поддержка нескольких голосов и ручного назначения голоса каждой реплике.
5. **Удобный редактор.** React + FastAPI: загрузка видео, таймлайн, правка перевода, прослушивание и повторная генерация отдельных реплик, предупреждения о длительности, экспорт.
6. **Перевод.** Пока ручной. Google Translate показал хорошее качество в браузере, но автоматическое подключение без официального API не удалось; интеграцию отложили.
7. **Надёжность.** Кэшировать готовые реплики, поддержать повторный запуск с места ошибки, тесты, логирование, конфигурацию и сборку полного видео.

## Замечания

- Это **прототип**, а не готовый продукт. Точность распознавания и качество озвучки требуют проверки носителем языка.
- Модель и входные медиа не включены в репозиторий. Учитывай лицензии моделей и права на фильмы и мультфильмы, особенно перед публикацией озвученных версий.
- На текущем тестовом компьютере используется CPU. Для ускорения обработки можно позже настроить GPU при наличии совместимой среды.
- Для воспроизводимого развёртывания после успешной установки выполни `uv lock` и добавь `uv.lock` в Git. В дальнейшем запускай `uv sync --locked`.

## Лицензия

Лицензия собственного кода пока не выбрана. Лицензии используемых моделей, библиотек и исходных медиа действуют отдельно.
